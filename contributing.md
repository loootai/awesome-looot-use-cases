# Contributing

Add a recipe under `use-cases/<slug>/README.md` and a row in the top README table.

- One job per recipe, stated in one sentence.
- Show the three ways to run it: an MCP client, the CLI and REST.
- Read prices from the free public catalog only, never from a paid run. Write the date next to every price.
- Use placeholder values such as `example.com`. No real people, no real emails, no tokens.
- Do not paste result bodies you have not seen. Describe fields only where the catalog describes them.
- Plain wording, no hype.
