A PreToolUse hook is a command you configure in `settings.json`. Claude Code runs it after Claude has built a tool call (like Bash, Edit, or Write) and before that call executes, passing it the tool name and inputs as JSON on stdin. The hook can allow the call, block it, ask the user for permission, or change the inputs, which makes it a good way to enforce rules like "never run `rm -rf`" or "lint every file before writing it."
