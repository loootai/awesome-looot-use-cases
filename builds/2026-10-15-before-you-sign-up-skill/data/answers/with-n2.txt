A PreToolUse hook is a command you configure in `settings.json` that Claude Code runs after Claude decides to call a tool but before the tool runs. The hook gets the tool name and input as JSON. It can then allow the call, block it (for example with exit code 2 and a reason that goes back to Claude), or modify the call, which makes it useful for enforcing rules like "never run `rm -rf`" or "lint before every edit."
