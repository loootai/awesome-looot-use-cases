Prices run from $0.00145 to $0.144 per call, about 99x apart. At 200 addresses, though, almost every option costs under $4, so price shouldn't decide this. What matters is how each provider handles catch-all domains, the servers that accept mail for any address. A "valid" from one provider and a "valid" from another don't always mean the same thing.

These are looot's list prices, not the prices on each vendor's own site. You can sign up with a provider directly or go through looot. Several vendors, ZeroBounce for example, have free tiers that might cover 200 addresses at no cost, so check their sites before you pay anyone.

## My pick

I'd use **MillionVerifier** if you only need a yes/no on deliverability. It's cheap and well established.

If a lot of your list is B2B, I'd pick **BounceBan**. Company domains are often catch-all, and BounceBan focuses on resolving those instead of returning "unknown." It costs $0.80 for the whole list.

## Plan

1. **Clean the CSV locally first. This is free.** Trim whitespace, lowercase, drop duplicates and rows that fail basic syntax. Flag role addresses like `info@` and `sales@`. This usually removes 5–15% of a list before you pay for anything.
2. **Check MX records locally. Also free.** A short Python script using `dnspython` can do a DNS lookup per domain. If a domain has no MX record it can't receive mail, so mark those invalid and skip the paid check.
3. **Run the survivors through the verifier.** You'd send one API call per address, or use the provider's bulk CSV upload. Both MillionVerifier and BounceBan let you upload a CSV in their web app, so you wouldn't need to write any code for 200 rows.
4. **Sort the results into four groups:**
   - `valid`: send.
   - `invalid`: remove.
   - `catch-all` / `risky`: send only if you can live with some bounces, or re-check them with BounceBan.
   - `unknown`: retry once a few hours later, since the receiving server may have been temporarily down or rate-limiting.
5. **Write an output CSV** with the original columns plus `status`, `reason`, and `checked_at`, so you can filter it in a spreadsheet.

Expect to pay roughly $0.30–$1 in total, and less if steps 1–2 remove addresses.
